### Changes since v0.1

- **PSP menu music:** the character select track now plays when the game is highlighted.
- **Stretched screen by default** (480x272). L+R+Select in game, or `screen=fit` in `settings.txt`, gives 4:3.
- **No log file by default.** Set `log=on` in `settings.txt` to report a problem.
- **README:** all settings, including how to unlock every character.

### Updating

Build a new `EBOOT.PBP` with the v0.2 builder and replace the old one. Saves are kept. An existing `settings.txt` keeps your screen mode.

### How to use it

1. Download the package for your computer.
2. Open the **MvC2 EBOOT Builder** and choose your own disc image of Marvel vs. Capcom 2 for PS2 (USA, SLUS-20486): `.iso`, `.bin`/`.cue`, `.cso`, `.zso`, or a `.zip` of one.
3. Copy the `MVC2` folder into `PSP/GAME/` on your memory stick (or open `MVC2/EBOOT.PBP` in PPSSPP).

**No game data is included.** Don't share the built EBOOT: it contains game data from your disc.

| Your computer | Package |
|---|---|
| Windows | `mvc2-psp-v0.2-windows.zip` |
| macOS (Apple silicon and Intel) | `mvc2-psp-v0.2-macos.zip` |
| Linux x64 / arm64 | `mvc2-psp-v0.2-linux-x64.tar.gz` / `mvc2-psp-v0.2-linux-arm64.tar.gz` |
| Anything with Python 3 | `mvc2-psp-v0.2-pypack.zip` |

The builders aren't signed; each package's README explains how to open them. The Python package needs the music encoder built first (see its README) for menu music.

### Needs and limits

- A PSP-2000 or later with custom firmware, or PPSSPP; about 200 MB free. The PSP-1000 isn't supported.
- On a real PSP, fights run at full game speed but the picture updates about 15–30 times a second.
