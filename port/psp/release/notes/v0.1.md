First public test release of Marvel vs. Capcom 2 for the PSP, built from the decompiled PS2 game.

**No game data is included.** You build the PSP game yourself from your own disc image of Marvel vs. Capcom 2: New Age of Heroes for PS2 (USA, SLUS-20486). The result is a normal, self-contained PSP game: one `EBOOT.PBP`, and the disc image isn't needed on the PSP.

### How to use it

1. Download the package for your computer (below).
2. Open the **MvC2 EBOOT Builder** and choose your disc image. It can be an `.iso`, `.bin`/`.cue`, `.cso`, `.zso`, or a `.zip` of one of these.
3. Copy the `MVC2` folder it makes into `PSP/GAME/` on your memory stick.
4. Play it from Game > Memory Stick (or open `MVC2/EBOOT.PBP` in PPSSPP).

Don't share the built EBOOT: it contains game data from your disc.

### Downloads

| Your computer | Package |
|---|---|
| Windows | `mvc2-psp-v0.1-windows.zip` |
| macOS (Apple silicon and Intel) | `mvc2-psp-v0.1-macos.zip` |
| Linux x64 / arm64 | `mvc2-psp-v0.1-linux-x64.tar.gz` / `mvc2-psp-v0.1-linux-arm64.tar.gz` |
| Anything with Python 3 | `mvc2-psp-v0.1-pypack.zip` |

The builders aren't signed, so Windows and macOS warn the first time you open them. The README in each package explains how to open them anyway.

### What you need

- A PSP-2000 or later with custom firmware, or PPSSPP. The PSP-1000 doesn't have enough memory.
- About 200 MB free on the memory stick.

### Known limits

- Fights play at full game speed, but on a real PSP the picture updates only about 15–30 times a second (frames are skipped to keep up). PPSSPP on a fast computer shows all 60.
- The PSP-1000 isn't supported.

Tested on a PSP-2003 (ARK-4) and in PPSSPP.
